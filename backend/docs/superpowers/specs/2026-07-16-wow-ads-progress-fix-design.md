# Исправление рекламы и прогресса Week over week

## Проблема

WoW дважды вызывает общий Ads builder: для текущего и предыдущего периодов. Builder после `fullstats` запрашивает
текущий бюджет каждой кампании, хотя WoW использует только `cart_adds` и `ad_spend_kopecks`. При 546 кампаниях это
создаёт до 1092 лишних запросов. Абсолютные смещения прогресса выходят за узкий диапазон WoW (`88–96` превращается в
`96–112`), после чего budget-stage откатывает процент назад. Frontend также слишком широко сопоставляет stage
`week-over-week`, поэтому разные этапы отображаются как текущий период.

## Решение

- Добавить Ads builder параметр `include_budgets=True`; передавать `False` только из WoW.
- Рассчитывать внутренние проценты относительно переданного диапазона и гарантировать монотонность.
- Namespace-ить source progress как current/previous и выделить диапазоны: sources current, sources previous,
  ads current, ads previous, summary.
- Сузить frontend stage matching до конкретных namespace.

## Проверка

Одна backend-регрессия проверяет отсутствие budget-запросов и границы процентов. Один существующий frontend source-test
получает проверку конкретных WoW stage matchers. Отдельный рекламный отчёт продолжает загружать бюджеты по умолчанию.
