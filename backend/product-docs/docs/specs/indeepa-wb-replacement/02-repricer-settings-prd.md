# PRD: Глобальные настройки репрайсера

## 1. Назначение

Собрать production-модель 17 глобальных параметров INDEEPA, которые влияют на расчет маржи, частоту пересчета, отправку цен, WB wallet, скидки, guards, логистику, локализацию и СПП.

## 2. Роли

- Мария: владелец бизнес-настроек.
- `settings_editor`: может менять параметры.
- `price_sender`: видит влияние настроек на отправку цен.
- Максим: подтверждает параметры маржи, логистики и расходов.
- Администратор: видит source/adapter impact.

## 3. Пользовательские сценарии

- Посмотреть текущие настройки и их влияние на расчет.
- Изменить параметр, увидеть diff, список затронутых стратегий и пример SKU.
- Сохранить настройки только после approval.
- Вернуть предыдущую версию настроек.
- Понять, почему изменение заблокировано: нет прав, зависит от неподтвержденной формулы, ломает guard.

## 4. Данные

`repricer_settings`:

- setting key, value, type, scope;
- default value Maria;
- allowed options;
- effective_from;
- version;
- actor;
- approval record;
- linked strategies;
- linked guards;
- audit event.

## 6. Presets и контролы

- margin mode: ForPay, RetailPrice, WalletPrice;
- schedule: 24 часовых окна и `Ежечасно`;
- send interval: `Не ограничивать`, 1-23 часа;
- WB wallet: 2%, 3%, 1%, 4%, 6%, 7%, 8%, 9%, promo 10%, WB Club 5%;
- allow/forbid для скидок;
- `3.1`: 1-90%;
- `3.2`: 1-100% и `Нет`;
- `3.3/3.4`: 10-100% и `Нет`;
- `3.6`: `Выключен`, 01-99;
- logistics history: no/use/use priority;
- boolean toggles for 4.2/4.3/5.1/5.2.

Важно: нельзя делать один generic percent select. У параметров разные диапазоны и смысл.

## 7. Бизнес-правила

- Изменение настроек сохраняется версионированно.
- Diff показывает старое значение, новое значение, затронутые стратегии, риски.
- Настройки применяются только к новым расчетам после effective time.
- При изменении guard-лимитов нужно пересчитать active drafts.
- Если настройка влияет на финансовую формулу, нужен finance approval или статус `unconfirmed`.
- UI не должен скрыто сохранять изменения.

## 8. Состояния

| State | Поведение |
|---|---|
| `loading` | Skeleton settings groups |
| `empty` | Нет настроек для scope/account |
| `error` | Не удалось загрузить/сохранить |
| `partial_data` | Параметр есть, но dependent source не подтвержден |
| `no_access` | Только read-only, без кнопки save |
| `diff_required` | Изменение есть, нужен preview |
| `approval_required` | Сохранение ждет подтверждения |

## 9. Опасные действия

Требуют approval:

- изменение 3.1/3.2 price limits;
- включение игнорирования лимитов;
- включение forecast СПП;
- смена margin mode;
- изменение schedule/send interval;
- разрешение отменять скидки.
