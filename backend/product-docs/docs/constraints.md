## Wildberries

### API-доступ

| Ограничение | Детали | Влияние на проект |
|---|---|---|
| **Автоакции WB — API не существует** | WB не предоставляет API для управления участием в акциях. Дорожной карты нет (апрель 2026) | Единственная защита — `min_price`: если акционная цена < P_min, WB не применяет скидку → SKU в акцию не попадает автоматически |
| **Personal Token запрещён для SaaS** | Правила WB: Personal Token только для собственного использования продавцом | Сейчас — Base Token. В будущем — Service Token через WB Catalog (когда станет доступен) |
| **API платный для SaaS** | Pay-as-you-go с **января 2026** | **Платит SaaS-сервис, не продавец.** Учесть в unit-экономике. Кэшировать всё что можно |
| **GET /api/v1/supplier/stocks отключается 23.06.2026** | Старый endpoint остатков | Использовать `POST /api/analytics/v1/stocks-report/wb-warehouses` |
| **HTTP 204 для пустых отчётов** | С **11.03.2026** пустые периоды возвращают 204, не `[]` | Парсеры должны различать 204 vs 200+`[]` — иначе падают на пустых датах |

### FBS и цены

| Ограничение | Детали | Влияние |
|---|---|---|
| **Дедлайн FBS 120 часов** | С момента оформления заказа покупателем | Штраф **50% стоимости товара без верхнего предела**. Таймер критичен |
| **Карантин цен WB** | Шаг цены ≥ 19% за час → цена замораживается | Блокировать изменения ≥19%/час на UI + алерт. Ночная медиана: шаг <19% |
| **Минимальная цена — P_min** | Если акционная цена < P_min, SKU не участвует в акции | Используется как защита. Не хак, а штатный механизм |

## Авито

| Ограничение | Детали | Влияние |
|---|---|---|
| **Messenger API требует тариф «Максимальный»** | ~**4 000 ₽/мес на каждый аккаунт**. Действует с **06.11.2025** | 10–15 аккаунтов × 4K = 40–60K/мес тарифов. Без этого тарифа уведомления ≤30с невозможны |
| **XML-фид: передавать ВСЕ активные объявления** | При каждом XML-обновлении. Пропущенные — Авито **деактивирует** | Blocker на частичные обновления. Pre-check `count(XML) ≥ count(DB active)` обязателен |
| **QR-код возврата Авито** | Отличается от первоначального. Доступность через Delivery API под вопросом | На этапе Discovery уточнить — возможно, QR возвратов доступен только через приложение. Если API не даёт — оставляем ручное получение + интерфейс массового оформления |
| **Запрещённые слова + запрет ссылок в чатах** | Авито блокирует сообщения с запрещёнными словами и ссылками | Бот-автоответчик должен прогонять все ответы через фильтр перед отправкой |
| **Блокировка за дубли фото** | Одинаковые изображения на нескольких аккаунтах = риск блокировки | Генерация фото нейросетью (3 lifestyle-варианта) — обязательная фича, не опциональная |

## Производство

| Ограничение | Детали | Влияние |
|---|---|---|
| **PDF-заказы в 8:00** | По будням. В выходные заказы копятся → единый PDF в понедельник | Cron-задача + обработка выходных |
| **Термопресс: 30–60 сек на цикл** | 40–120 изделий/час. Полный цикл заказа (пресс + упаковка + стикер) 5–8 мин | Группировка по принту — критично для производительности |
| **Склад = бланки, не готовые SKU** | Белые/чёрные футболки по размерам. Готовый SKU появляется при печати | Логика остатков отличается от типового e-comm |

## Честный знак (КИЗ)

| Ограничение | Детали | Влияние |
|---|---|---|
| **Каждый КИЗ одноразовый** | После привязки к заказу — вычёркивается из пула | Автосинхронизация пула. Запрет повторного использования |
| **Пустой пул КИЗ = стоп FBS** | Без КИЗ нельзя отгружать → нельзя формировать PDF | Алерт в Telegram при пороге (настраивается), блокер на формирование PDF при 0 |

## Данные и интеграции

| Ограничение | Детали | Влияние |
|---|---|---|
| **1С — две базы с ошибками** | Управленческая + бухгалтерская, расхождения | Интеграция двусторонняя, но с валидацией на нашей стороне. Не доверять данным «как есть» |
| **WB API нестабилен** | Меняется без предупреждения (прецеденты: deprecation endpoints, формата ответов) | **Adapter pattern с первого дня**. Изолировать слой API от бизнес-логики. Логировать все запросы/ответы для диагностики |

## Что явно НЕ реализуется

Из ТЗ и CLAUDE.md (чтобы не возвращаться к спору):

- Автозапуск ликвидации без менеджера
- Конкурентное следование цен (это INDEEPA, у нас demand-based)
- «Красивая цена» (округление до 9)
- ABC-анализ в репрайсере (только в отчётах)
- План-факт
- Обещание UI для управления автоакциями WB (API не существует)
