# 2026-06-05

- Для WB repricer подключён finance snapshot через новый `POST /api/finance/v1/sales-reports/detailed`; deprecated `reportDetailByPeriod` не используется для новой экономики SKU.
- Finance данные сначала сохраняются в существующий `wb_repricer_source_cache` как `finance_{periodDays}`: raw rows + агрегаты по `nmId`.
- Маппинг экономики: `commission_percent` / `ppvz_sales_commission`, `sale_percent` только скидка, `dlv_prc` не используется как рублёвая логистика, logistics берётся из денежных полей с fallback-порядком.
- ABC в repricer считается после загрузки finance cache: первая буква по sales/orders/revenue rank, вторая по `netProfitKopecks`, пороги 20/30/50.
- Если finance cache ещё не загружен, frontend показывает `нет данных` для ABC/маржи/комиссии/логистики/хранения вместо шаблонных значений.
