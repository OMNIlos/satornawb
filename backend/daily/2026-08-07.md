# 2026-08-07

- Avito returns: принято решение хранить товары в возврате в отдельной таблице `avito_return_items`, а не в кэше заказов, чтобы подсказки на странице заказов работали от устойчивого inventory.
- `on_return` считается сразу пригодным для повторного использования: периодический Celery sync забирает Avito orders со статусом `on_return`, извлекает позиции и upsert-ит их в БД.
- Матчинг заказа с возвратом: сначала `sellerArticle + size + color`, затем `title + size + color`; конфликтующие размер или цвет не матчим.
- Реализация описана в `docs/superpowers/specs/2026-08-07-avito-return-inventory-matching-design.md` и плане `docs/superpowers/plans/2026-08-07-avito-return-inventory-matching.md`.
- Frontend source-of-truth остается `ogni-react-frontend/frontend/public/vella-production.html`; добавлена подсказка `В возврате есть такой же товар`. Targeted frontend test сейчас упирается в уже существующий mismatch `REPORT_TABS` / `orders-print`.
