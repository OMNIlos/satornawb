## Реализовано

- Существующий CostsService: серверная дата изменения, immutable версия,
  expectedCostVersionId, повтор по sourceReference, автор membership.
  Блокировка CatalogSku сериализует записи PostgreSQL; локальный SQLite editor
  использует BEGIN IMMEDIATE. Исторический API также блокирует строку SKU.
- Catalog API current-cost: права catalog/costs, организация, account scope
  для всех затронутых связанных offers. Legacy-таблица без account identity
  допускается только при единственном connected WB-аккаунте. Неоднозначные
  mapping/размеры блокируются, произвольного создания mapping нет.
- Колонка «Себестоимость, ₽/шт.» и CurrentCostEditor. Загрузка значения по
  запросу пользователя, без 150 фоновых запросов при открытии страницы.
  Enter/кнопка, Escape, точные копейки, серверное подтверждение, retry key,
  сообщение о конфликте с сохранением ввода, подтверждение shared cost.
- После записи запрос существующей страницы/summary, без обращения к WB.
- Дневной исторический расчёт не применяет внутридневную правку ко всем
  продажам дня: расхождение opening/closing cost version оставляет COGS unknown.

## Карта потребителей и незавершённость

| Потребитель | Источник и статус |
|---|---|
| Новый input | CatalogCostVersionRow через CostsService, текущий момент |
| Settlement summary/ABC | legacy_tax → CostsService, датированные дневные units; внутридневная неопределённость блокируется |
| Canonical P&L/ABC | существующий CostsService; политика расчёта отдельная, не объявлена эквивалентной новому settlement |
| Legacy стратегия/минимальная цена | settings.cogsKopecks; перенос на общую current-cost projection НЕ завершён |
| Legacy статистика, симулятор, XLSX | нужна дальнейшая проверка/перенос; не утверждать сквозной parity |

Следовательно, ввод ещё нельзя считать полностью интегрированным во все
финансовые/торговые consumers. Production-выпуск запрещён до закрытия этого разрыва.
Нет полной browser-проверки конфликта/перезагрузки, неизвестных аккаунтов,
mobile/200%; нет PostgreSQL concurrency-прогона. Отдельно остаются заказы ₽,
inSale по размерному варианту, совместные комментарии и fake-стратегии.
Чужие/реальные данные не менялись, реальные финансовые суммы не сверялись.
